Know a tool that helps with research? Add it below. We check the link, add a screenshot,
and a maintainer reviews it before it is listed.

**All submitted content is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).**
Everyone, including you, can then use it freely. Please do not submit anything if you do not agree.
See the [About page](/about/) for how to use the content.

We list tools built for research work. Pages made for ranking, and tools meant to make AI-written
text pass as human, are not accepted.

## Prefer a pull request?

Fork [kausalflow/tools](https://github.com/kausalflow/tools), copy an existing file in
`content/tools/` and open a pull request. Allowed categories, fields and platforms are listed in
`scripts/triage/taxonomy.yaml`, and a check validates new entries.

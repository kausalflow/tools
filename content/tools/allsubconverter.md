summary: AllSubConverter is a browser-based subtitle toolkit for researchers, educators, translators, and video teams. It supports converting, editing, cleaning, syncing, checking, and exporting captions for recorded lectures, seminars, interviews, and multilingual media across SRT, VTT, ASS, SSA, LRC and related formats. Standard processing runs in the browser without file upload or account signup, while optional AI features use the user's own API key.
features:
- Converts between subtitle formats including SRT, VTT, ASS, SSA, LRC and more
- Cleans duplicate, blank, or malformed cues and checks timing, overlaps, CPS, and line length
- Edits, syncs, merges, splits, adjusts frame rates, and prepares batch subtitle workflows
- Exports subtitles or PDF for review, quotation, annotation, and publication
- Standard processing runs locally in the browser; optional AI uses the user's own API key

title: UnoRouter
summary: UnoRouter is an LLM API gateway for researchers who want to compare or script many language models without signing up with each vendor. One OpenAI-compatible key reaches GPT, Claude, Gemini, Llama, DeepSeek, Qwen and Mistral models, so an evaluation notebook or annotation script can switch models by changing a single string. Some models are free, the rest are billed per token with no subscription, and the whole stack is open source.

features:

- Works with the official OpenAI Python and JavaScript SDKs
- Free models for small experiments, pay-as-you-go above that
- Automatic failover when a provider is down
- Open source code
- Browser chat that keeps history locally

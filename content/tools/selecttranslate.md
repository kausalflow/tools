summary: SelectTranslate is an AI-powered browser translation extension that helps researchers, students, and academics access multilingual research materials. It supports bilingual webpage reading, side-by-side PDF translation, and scanned document translation, making it easier to read academic papers and compare translated content with the original text. It also supports multiple AI models, custom API keys, and local models via Ollama.

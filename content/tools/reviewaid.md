title: ReviewAid
summary: ReviewAid is an open-source AI tool that speeds up systematic reviews by screening full-text papers against PICO criteria and extracting key data fields, acting as an AI-assisted second reviewer with confidence scoring.
features:
- Full-text screening using PICO criteria with inclusion/exclusion classification
- Custom data extraction from full-text articles
- Batch processing (up to 20 papers per run)
- Confidence scores for AI decisions
- Export to CSV, Excel and Word
- Configurable models (OpenAI, Claude, DeepSeek, Cohere, Ollama and others), with a local offline mode via Ollama

title: RetexPDF
summary: RetexPDF is an open-source agent skill for researchers who want to read academic papers in another language. It uses Codex to translate PDF text and produce a searchable PDF plus editable LaTeX, with original equations, figures, tables and references retained as vector fragments. Text is reflowed into a single-column article rather than preserving the original page layout. It works best with selectable text; scans and complex layouts may need manual correction.

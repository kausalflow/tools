title: zoteroplugins.org
summary: 'A free catalogue of ~1,600 Zotero plugins, for researchers and students who use Zotero. For each plugin it shows which Zotero versions it works with, what its code sends where, how actively it is maintained, and a plain-language grade, so you can pick plugins that work and are safe to install. Disclosure: I run it, as one person; no ads.'
images:
- path: home.png
features:
- Which Zotero versions each plugin works with.
- What each plugin's code sends where, and whether it needs an API key.
- Maintenance status and last release.
- A plain-language grade with the reasons behind it.
- Replacements for plugins that stopped working after Zotero 6.
- A free check for library guides that recommend plugins.

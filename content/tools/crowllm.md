title: CrowLLM
summary: CrowLLM is an OpenAI-compatible LLM gateway that reaches 147 hosted models, including 39 free-tier ids (31 priced at zero), through a single key, so an evaluation notebook, annotation pipeline or agent script can switch models by changing one string. It is free-tier-first with per-token pay-as-you-go above that, needs no card at signup, and publishes a keyless model catalogue and pricing feed that can be read programmatically before spending anything.

features:
- One OpenAI-compatible endpoint at https://crowllm.com/v1 for every model
- Works with the official OpenAI Python and JavaScript SDKs
- 39 free-tier ids, 31 of them zero-priced; small paid usage is per token
- Keyless /v1/models and /api/pricing feeds for reproducible model and price checks
- Streaming, tool calling and per-token USD pricing
